Application Overview

Application Name : evmdmsuppliertosailpoint

Type of Application


Orchestration Application

Runtime Migration Version


4.9

Analyst


Sravani Simhadri

This evmdmsuppliertosailpoint is an application which fetches supplier and contact related information from reltio based on the entity id. The input payload for this application is received in the queue from an enriched application. After processing the data from reltio this app maps the fields to the sailpoint fields to store the relevant data. This application will use three methods GET, PUT and POST.
